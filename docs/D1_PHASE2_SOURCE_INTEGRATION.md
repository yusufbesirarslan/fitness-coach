# D1 Phase 2 source integration

This change prepares five distinct purpose projections and a finite source-only allowance installer. `POLICIES`, `PUBLISHED_TEXTS`, and `APPROVED_POLICY` remain empty/inactive. All existing endpoint holds remain. It does not activate AI or publish the proposed categories, quantities, recipients, models, or legal text as approved facts.

Native Coach, Pump and QR physical calls require original operation authority; a Pump `vision` projection cannot enable an unqualified legacy image path. Cross-feature nested calls still refuse. `PHYSICAL_FEATURES` remains accounting only. Coach food/image tools and QR nested nutrition/non-AI recipient boundaries need approved scope and composition before endpoint opening. Streaming, memory, comparisons, OCR and unsupported replacements remain closed.

The mobile change depends on the read-only `GET /api/v1/ai/actions/{coach|nutrition_generation|qr_menu}` receipt. It uses the authenticated owner and `Idempotency-Key` header, returning only contract version, feature and `UNKNOWN`, `PENDING`, or `TERMINAL`. It does not settle, expire, authorize, return protected results, or mutate balances. Missing, purged, foreign and historical unbound records remain indistinguishably `UNKNOWN`. Even an expired `RESERVED` row stays `PENDING` until existing settlement records a terminal state.

A terminal receipt allows the mobile client to reconcile a lost response without another AI POST; starting another action requires a separate explicit submission. An unknown receipt never authorizes a replacement key. Durable result redelivery is not introduced. Training/Pump retain their existing recovery contracts.

The generic allowance error envelope now exposes only customer feature/scope/reset metadata for exhaustion and feature-not-in-plan. Existing subscription authority, physical budgets, spend guards, transaction/lock ordering and historical grants remain unchanged.

Endpoint opening still requires approved exact contracts/EN/TR text and route facts, finite policy installation, signed eligibility owner qualification (13–17 AI remains pending), and scoped Coach/QR tool composition or an approved bounded tool-free scope. The decision package `axisai-d1-allowance-launch-closure-01/D1_ALLOWANCE_LAUNCH_DECISION.md` remains the policy decision authority. No deployment, migration execution, AWS mutation, merge or paid provider qualification is authorized by this source change.
