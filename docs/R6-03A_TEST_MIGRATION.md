## Regressions found during recovery (D)

Failing tests preceded each fix: fresh route proof before old-backend retirement and candidate removal; previous backend liveness proof on preswitch rollback; same-SHA candidate binding to the newly built immutable image; unproven failed-migrator cleanup prevents a verified rollback claim; compound HostOps share a decreasing deadline; shell cleanup fits one reserved phase. Compose auto-removal is accepted only after bounded absence proof matching the explicit Docker response for that named container; missing daemon sockets fail closed.

## Qualification

Critical mutation qualification runs in disposable source copies and checks byte-exact worktree preservation. All 23 mutants were killed locally after the engine fixes. The harness and CI artifact retain each assertion failure and source hash. Local modeled orchestration does not replace the retained real Docker/nginx/image CI gates.

Production remains out of scope; R6-03B owns the separately approved first production deployment.
