{#- Progress V2 PR1 · ProgressCurrentState — "What is my current state?" Owns exactly three things: the concise trajectory-level state (#ps-state headline + #ps-lede summary), the evidence it is based on (#ps-meta: the analysis window) and the recommended next action (#ps-next). It does NOT say which signal drives the state — that interpretation belongs to Axis Insight — and it does NOT restate measurable evidence the Trends section owns (weights, counts, consistency). The state is decided by the server (GET /api/progress/summary → app/services/progress_summary) and mapped to copy by static/progress_presentation.js. The markup ships neutral copy, which is what a reader sees before the summary resolves. data-state on .ps-card drives the accent only — the state is always spelled out in #ps-state text as well, so it is never carried by colour alone (WCAG 1.4.1). -#}
